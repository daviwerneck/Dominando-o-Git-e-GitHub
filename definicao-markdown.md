Markdown é uma linguagem de marcação leve utilizada para formatar textos de maneira simples e organizada. Ela permite criar títulos, listas, links, imagens, tabelas e outros elementos utilizando uma sintaxe fácil de aprender. Exemplos: # Título | ## Subtítulo | **Texto em negrito** | *Texto em itálico* | [Link](https://exemplo.com)
